# Latencia

fiz esse projeto pra ser uma ferramenta simples pra testar e acompanhar a internet sem depender de abrir site toda hora

Ele vai medir download, upload, ping, jitter e perda de pacotes. Também tem monitor de latência, diagnóstico básico, histórico dos testes, mostra algumas infos da rede e essas firulas ai

Pra quem só vai usar o programa, a ideia é bem simples mesmo: baixa a versão pronta, abre o `Latencia.exe` e usa. Não precisa instalar Python nem ficar rodando comando.

O código fonte fica separado pra quem quiser mexer no projeto. Se eu quiser gerar uma nova versão no Windows, é só abrir o `build_release.bat`. Ele monta a pasta pronta dentro de `dist`.
